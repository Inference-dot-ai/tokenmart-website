## What is xAI API Pricing?

**xAI API pricing** is defined as the per-token cost structure charged to developers for accessing xAI's Grok language models programmatically. Unlike consumer subscriptions on the X platform, the API operates strictly on a pay-as-you-go model. You are billed based on the exact volume of tokens processed during your application's requests.

In August 2026, the official **xAI API pricing** strategy features a multi-tiered approach based on model intelligence and speed. The costs are broken down into input tokens, cached input tokens, and output tokens. Input tokens are the words you send to the model. Cached input tokens are repeated prompts that the system remembers, which cost significantly less. Output tokens are the generated responses.

Prompt caching is a major factor in calculating what you actually pay. When you send a large system prompt repeatedly, xAI stores it temporarily. If your subsequent requests use that exact same prompt prefix, you receive a massive discount.
