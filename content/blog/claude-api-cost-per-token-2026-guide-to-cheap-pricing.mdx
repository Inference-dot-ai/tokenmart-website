To understand this, you must first understand what a token is. When you make a request to the API, you are billed based on the sheer volume of these tokens. Because this rate dictates your entire infrastructure budget, mastering the pricing structure is vital for commercial viability. ### Understanding Input vs. Output Tokens
The **claude api cost per token** is fundamentally split into two distinct categories: input tokens and output tokens. Input tokens represent the text you send to the model, including your system instructions, prompts, and contextual data. Output tokens represent the text the model generates in response. Output tokens are historically more expensive than input tokens because generating new text requires significantly more computational power than reading provided text.
