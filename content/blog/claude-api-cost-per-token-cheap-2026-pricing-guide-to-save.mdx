## What is the Claude API Cost Per Token?

The **claude api cost per token** is defined as the fraction of a cent you pay Anthropic for processing chunks of text, code, or data. In the world of LLMs, a "token" is roughly equivalent to a common word or a piece of a word. When you send a prompt to an AI model, the system measures your usage in tokens rather than characters or bytes. This precise measurement dictates your final bill. 

Understanding the **claude api cost per token** requires splitting your usage into two distinct categories: input and output. Input tokens represent the text, images, and system instructions you send to the AI. Output tokens represent the text the AI generates and sends back to you. The rate for outputs is strictly higher than for inputs. In fact, output tokens usually cost five times as much as input tokens across all current Anthropic models. 

This structure penalizes long, unchecked AI responses. If you deploy an application that generates endless paragraphs of text, your expenses will multiply rapidly.
