Input tokens are defined as the literal text data you transmit to the language model. This broad category includes your hidden system prompts, active user queries, and any attached reference documents. Output tokens are defined as the resulting text data the model actively generates in response. 

Output tokens remain universally more expensive within standard **openai api pricing** because generating new information is remarkably demanding.
